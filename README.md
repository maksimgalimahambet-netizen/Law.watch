# ⚖ LawWatch

Қазақстан құқықтық актілерінің каталогы, құқық саласына бағыттау және жеке мерзімдер.
Каталог законодательных актов Казахстана, подбор области права и личные сроки.
A catalog of Kazakhstan legal acts, legal-area guidance and personal deadlines.

## Мүмкіндіктер / Возможности / Features

- Заңдар каталогы, іздеу және санат сүзгісі / каталог, поиск, фильтры / catalog with search and filters
- Әділет (adilet.zan.kz) ресми сілтемелері / ссылки на официальный текст / links to official texts
- Құқықтық бағыттау (кілт сөздер бойынша) / навигатор по ключевым словам / keyword-based guide
- Еске салғыштар және Calendar `.ics` экспорты / напоминания и экспорт `.ics` / deadlines with `.ics` export
- Таңдаулылар / избранное / favorites
- Тілдер: KZ, RU, ENG
- Көк-ақ дизайн, анимациялар, мобильді нұсқа / сине-белый дизайн, анимации, адаптив

## Іске қосу / Запуск / Run

Сервер де, құрастыру да қажет емес. `index.html` файлын браузерде ашыңыз.
Сборка не нужна, просто откройте `index.html` в браузере.
No build step: just open `index.html` in a browser.

## GitHub Pages

1. Репозиторийге файлдарды жүктеңіз (`index.html`, `README.md`, `.nojekyll`).
2. **Settings → Pages → Build and deployment**.
3. Source: **Deploy from a branch**, branch: `main`, folder: `/ (root)` → **Save**.
4. Бірнеше минуттан кейін сайт `https://<username>.github.io/<repo>/` мекенжайында ашылады.
